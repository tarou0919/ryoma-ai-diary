前回、1週間かけて銀行明細の仕訳ツールを作り、ココナラに出品したところまで書きました。

出品した。Xにも投稿した。あとは反応を待つだけ。そう思っていました。

今回は、その「待つだけ」の期間に何が起きていたかの記録です。

## Day 9:ダッシュボードを開いた日

出品から2日後。Day 8 は完全に休んでいたので、実質的には翌営業日です。

なんとなくココナラの管理画面を開きました。そこに出ていた数字が、これです。

- 閲覧数(過去30日):**102回**
- 販売数:**0件**
- お気に入り:**2件**
- 販売額:**0円**

通知が来ないな、とは思っていました。でも「まだ誰も見ていないだけ」だと思い込んでいたんです。

実際は、102人が見に来ていた。そして、何もせずに帰っていた。

これは想像していたよりこたえました。見られていないなら「まだ届いていないだけ」と思えます。でも見られた上でのゼロは、そうは思えません。

## もうひとつの衝撃:13個も出していた

同じ画面で、もっと間抜けなことに気づきます。

**自分が13個もサービスを出していた**ことに、その時まで気づいていませんでした。

感覚としては「3つくらい出しているかな」でした。実際には、作っては出し、作っては出しを繰り返した結果、管理画面に13行並んでいた。半分以上は、出したこと自体を忘れていました。

ジャンル別に書き出すと、こうなります。

- 経理・会計の自動化:6個
- 製造業向けの管理システム:2個
- 競馬予想、投資ロジック:2個
- AI関連の単発相談:2個
- 経理系で機能が重複したもの:1個

戦略があって13個になったわけではありません。「作れたから出した」の積み重ねです。

作れるようになったこと自体は、前回書いたとおり嬉しい変化でした。でもその嬉しさのまま、作れるものを片っ端から並べていた。並べれば、どれかは当たると思っていたんだと思います。

当たりませんでした。

## 規約という、見えていなかった地雷

Day 9 から Day 16 にかけて、いちばん時間を取られた作業がこれです。

実は少し前に、レシートOCRと請求書OCRが運営から取り下げられていました。通知に書かれていた理由は2つです。

- 実績の数字を、対象期間や対象データの全体を示さずに記載している(景品表示法違反)
- 直接やり取り可能な外部サイトの情報を掲載している

具体的に引っかかっていた表現が、これです。

- 「100%実証済み(24/24項目)」
- 「100%抽出成功(27/27項目)」
- 「月4時間→10分に短縮」
- 「1〜2ヶ月で元が取れる」
- 「Zoom」という外部サービス名
- GitHub の URL

見返して青くなりました。**これらの多くは、AIに書かせた文章をほぼそのまま貼ったものです。**

AIは、魅力的な商品説明を書くのが上手です。数字を入れて、効果を断定して、読み手が動きたくなる文章を出してくる。そして、それが規約に触れるかどうかは判断してくれません。少なくとも、こちらが聞かない限りは。

さらに情けなかったのが、**一度取り下げられた経験があるのに、他のサービスに同じ違反がそのまま残っていた**ことです。

取り下げられたサービスだけ直して、終わったつもりでいました。Day 9 に請求書OCRを見直して2箇所、Day 11 に Excel請求書を見直して5箇所。本文だけでなく、FAQ やオプションの説明欄にも埋まっていました。

修正は、だいたいこういう変換になります。

| NG | OK |
|---|---|
| 100%、99% | 具体的な機能を列挙する(7項目、9項目) |
| 3時間→10分 | 「対応可能な作業例」として書く |
| 完全に手放す | 解放する |
| Zoom | ビデオチャット |
| GitHub の URL | ソースコード付き(MIT) |
| 5分で完了 | サポートいたします |

地味です。そして時間がかかります。1サービスあたり、最低でも30分から1時間。FAQ もオプション欄も、全部開いて確認する必要があります。

コードを書いている時間より、この作業のほうが長い日がありました。

## 「捨てる」の基準を、言葉にする

Day 13 から 16 にかけて、13個を6個まで減らしました。

最初は直感でした。閲覧数が一番多かった請求書OCR(¥80,000)と、お気に入りが付いていたAI競馬予想(¥25,000)の2つに集中しよう、と。

でも進めるうちに、「何を残すか」より「何を捨てるか」を考えたほうが判断が早いと気づきます。最終的に、以下のどれかに当てはまるものを非公開にしました。

1. **法的・規約リスクが高い** — ギャンブル、投資助言と誤解されうるもの
2. **タイトル自体が規約違反** — 「月4時間→10分OCR」がそのまま該当しました
3. **ターゲットがココナラにいない** — 製造業の生産管理システムを、個人向けマーケットで売ろうとしていました
4. **AIで代替される** — グラフ化ツールは、ChatGPT に頼めば済みます
5. **単発で薄利** — 続けるほど赤字になるもの

この基準に照らすと、製造業向けの2つは即アウトでした。自分が製造業出身だから作れた、というだけで、買う人がそこにいるかを考えていませんでした。

いちばん迷ったのは、AI競馬予想です。

お気に入りが2件付いていました。13個のうち、反応らしい反応があった数少ないサービスです。「唯一の手応えを、自分から消すのか」とかなり悩みました。

それでも消しました。ギャンブル関連は規約と法律の両方でリスクがあり、仮に売れても続けられない。手応えがある方向と、続けられる方向は、必ずしも同じではありませんでした。

残した6つには、後から共通点を見つけられるようになりました。経理・会計の自動化という一貫したジャンルで、買い切りのツール型で、規約セーフに書き換えられて、¥6,000 から ¥80,000 まで段階を作れて、自分が業務を理解できているもの。

この言葉が出てきたのは、捨て終わった後です。順番としては、捨てながら基準ができていきました。

## 価格は、変えませんでした

ひとつだけ、この期間に動かさなかったものがあります。価格です。

請求書OCR の ¥80,000 は、Day 9 の時点でも、整理が終わった Day 16 の時点でも、同じままでした。

「¥80,000は中小企業向けで、個人事業主には高いのでは」という話は、Day 13 の分析で出ていました。実際、閲覧はされても売れていない。下げれば動くかもしれない、とも考えました。

それでも据え置いたのは、安くしたところで「買う理由」が生まれるわけではないと思ったからです。売れていない原因が価格なのか、それ以外なのか、この時点では分かっていませんでした。分からないまま値段だけ動かすのは、いちばん学びが少ない打ち手に思えました。

結果として、この判断が正しかったのかは、まだ分かりません。

## この期間で学んだこと

**1. 数字を見るまで、自分の状況は分からない**

通知が来ないという感覚と、102回見られて0件という事実は、まったく別物でした。ダッシュボードを開くまでの2日間、私は何も知らないまま「待って」いました。

**2. 量を並べても、確率は上がらない**

13個あっても、ジャンルがバラバラなら、誰にとっても「専門の人」に見えません。6個に絞って初めて、経理まわりの人、という顔ができました。

**3. AIの書く文章は、規約を知らない**

これは、これからAIを使って何かを売る人全員に関係する話だと思います。生成された文章をそのまま貼るのは危ない。特に数字と、効果の断定です。

**4. 捨てる判断には、手応えを手放すことが含まれる**

お気に入り2件を消すのは、思ったよりきつい作業でした。

## あなたに聞きたいこと

いま、手元にいくつ「作ったまま放置しているもの」がありますか。

私は13個ありました。しかも13個あることに気づいていませんでした。棚卸しをしただけで、見える景色がかなり変わります。

もし何かを作って売ろうとしている方がいたら、一度そのプラットフォームの管理画面を開いて、数字を見てみてください。見たくない数字が出てくるかもしれませんが、見ないままの2日間よりはましでした。

次回は、この後に取った「完全に休む1週間」について書きます。手を動かさないことが、いちばん効いた週の話です。
